# 프롬프트 버전 관리

프롬프트는 코드다. 이 디렉토리의 파일이 파이프라인이 로드하는 원본이며,
**파일명에 버전을 박는다** (`extract_utterances_v1.md`, `_v2.md`, ...).

규칙:
- 기존 버전 파일은 절대 수정하지 않는다 — 새 버전 파일을 만든다
  (utterances.prompt_version 컬럼이 이 파일명을 참조. 수정하면 과거 데이터 재현 불가)
- 버전 올릴 때 PR에 변경 이유 + 500건 육안 점검(§14 W5~6) 결과 링크
- 프롬프트 변경 PR은 상호 승인 필수 (스키마 §7·지표 §8과 동급 자산)
