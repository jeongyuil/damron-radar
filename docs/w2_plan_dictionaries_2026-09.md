## 0. "사전"의 정의를 먼저 맞춘다

PRD는 사실/주장/의견·감성·입장을 **LLM이 분류**하는 구조(§6.2·§6.3)다. 따라서 여기서 사전은 규칙 기반 분류기가 아니라
**① 프롬프트에 주입되는 참조 자료 ② 검수(§9) 기준 ③ 전사 정규화 테이블** 세 가지다. 골든셋 1차 결과가 사전이 필요한 자리를 정확히 보여줬다:

| 골든셋 오답 패턴 | 필요한 사전 |
|---|---|
| "들었다·요약하면·얘기하더라" 전언 표현을 전부 claim으로 과적용 (4건) | 팩트체크: **판례집(decision book)** — §6.2 각주가 명시한 자산 |
| fact 3건 전부 놓침 — STT 오탈자 속 근거(수치·출처)를 인식 못 함 | 팩트체크: **근거 신호 어휘** + 클렌징: **STT 정규화** |
| stance 방향 일치 28.6% — 이슈별 부호 방향이 정의돼 있지 않음 | 감성·입장: **이슈별 stance 부호 규칙** |
| neutral을 negative로 편향 (7건 중 4건) | 감성: **정치 어휘 감성 사전 + 반어·인용 예외** |

## 4. 의존·리스크

- **Snowflake 전사는 타임스탬프가 없고 10,000자 절단** — 어휘 추출 입력으로는 쓸 수 있으나 판례집(C)의 타임스탬프 링크는 파일럿·골든셋 전사에서만 딴다. 성환 수정 후 재확인.
- 골든셋이 13건·claim 0건이라 검증은 방향성만. 2주차 중 성환에게 **claim이 나올 논객 채널 영상 1편 추가 라벨링**을 요청(3주차 평가 입력 겸).
- 감성 사전은 LLM 분류를 대체하지 않는다. 검수 샘플링(§9)에서 "사전 극성과 LLM 판정이 어긋나는 건"을 우선 검수 큐에 올리는 용도다 — 이걸 성환에게 명확히 말해 기대치 차이를 없앤다.
- 댓글 데이터는 감성 사전 소스로 쓰지 않는다(비범위·개인식별자).
